# Golden set

This directory intentionally contains no user images or labels. Add real, consented
saved-look images here and label them with `python -m eval.label` before evaluating a
live provider. Keep image files in `images/` and one JSON label per look in this folder.

Do not seed this set with clean product photography: the build specification requires
real saved collections, including mirror selfies, warm lighting, crops, and crowded
frames.
